=== FEATURE 1: RECENT WORK CAROUSEL ===

PLACEMENT

section and the "Select Work" section. Nothing above or below it moves or changes 
other than being pushed down.

DATA MODEL
Create a table/collection called `recent_work` with these fields:
- id (primary key, auto-generated)
- type (enum/string: "photo" or "video")
- embed_url (string) — YouTube embed link for videos, image embed link for photos
- title (string)
- category (enum/string: "Music", "Sports", "Hospitality & Events")
- date_added (timestamp, defaults to now)
- active (boolean, defaults true) — controls whether the item appears in the carousel

CAROUSEL BEHAVIOR
- Queries `recent_work` WHERE active = true, ORDER BY date_added DESC, LIMIT 10
- Horizontally scrollable carousel with left/right arrow navigation
- Renders video items as YouTube embeds/thumbnails and photo items as images, 
  based on the `type` field
- Each card shows the title and category as a small label beneath it
- Responsive: multiple cards visible on desktop, single-card swipe on mobile
- If there are zero active items, hide the entire section rather than showing an 
  empty state
- Section header should read "RECENT WORK" in the same header style used elsewhere 
  on the site
